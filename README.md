# YuiDesk · 多角色桌面 AI 宠物助手（Kimi 双引擎）

一款面向 Windows 的轻量多角色桌面宠物与 AI 工作/聊天助手，内置 3 套全动画角色（共 90 帧），支持**官方 Kimi Code CLI 本机中转**与**Kimi 官方 API Key**双引擎、独立离线养成系统、实时任务阶段进度、多任务后台并发，以及带 SHA-256 校验与国内镜像回退的内置自动更新。

## 核心亮点

- **多角色全动画桌宠（内置 3 套 · 90 帧）**：轻音元气少女、桃橘小狐狸·四足原生态版、桃橘小狐狸·Q版站姿，支持右键一键切换及导入 PNG / GIF / ZIP 自定义皮肤。
- **工作 / 聊天双模式与多任务并发**：
  - 左侧类 Kimi 可折叠记录栏，严格隔离项目任务记录与日常聊天记录及记忆策略。
  - **实时阶段进度卡片**：执行多步任务时实时展示工具调用、阶段说明、完成标记与耗时，历史步骤可随时展开回看。
  - **后台并发与无感切换**：工作任务运行时可随时切换到「聊天」模式或查看其他项目，左侧栏与模式标签实时显示运行动画；切回原任务自动续接进度，随时点击「停止」可彻底终止子进程树。
- **独立离线养成系统**：互动陪伴、小卖部与背包、每日任务与成就，零联网、零 Token 消耗。
- **零依赖绿色便携版 + 内置自动更新**：
  - 便携包内置 VC++ 运行库、Kimi 引擎与精简便携 Bash 环境，朋友拿到手无需安装 Python 或 Git。
  - 内置自动更新支持 GitHub 官方 Release 与国内镜像加速回退，所有更新包强制通过 **SHA-256 完整性校验** 与 **Zip-Slip 路径安全检查**，升级不改动 `%APPDATA%\YuiDesk` 用户数据。

## 安全说明

- 本地后端严格仅监听 `127.0.0.1` 随机端口，不对外网或局域网开放。
- 禁用通配 CORS，启用 `Host` / `Origin` / `Sec-Fetch-Site` 校验防御 DNS Rebinding 与跨站 CSRF。
- 所有本地 API Key 均通过 Windows DPAPI (`CryptProtectData`) 加密保存。
- 自动更新固定绑定官方仓库，强制验证 SHA-256，更新前必须由用户手动确认。

## 下载与使用

1. 前往 [Releases](https://github.com/tjcisyourdady-gif/YuiDesk/releases) 下载最新版 `YuiDesk_便携版.zip` 并**全部解压**到普通文件夹。
2. 双击 `YuiDesk.exe` 启动，右键桌宠 →「设置」完成 Kimi 登录或填入 API Key。
3. 后续发布新版本后，直接在桌宠「设置 → 快捷键与历史 → 软件自动更新」中一键检查并更新（约 20 MB 轻量补丁包），无需再手动重发完整安装包。

## 开发与打包

```powershell
# 开发模式运行
.\.venv\Scripts\python.exe main.py

# 一键打包（生成便携目录、完整包、增量更新包与 latest.json）
.\build.ps1
```
